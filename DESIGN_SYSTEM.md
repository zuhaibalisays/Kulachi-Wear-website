# KULACHI WEAR — DESIGN SYSTEM

## Brand personality

Modern • Elegant • Feminine • Confident • Refined • Premium

The visual goal is quiet luxury rather than flashy luxury.

## Core palette

| Token | Hex | Usage |
|---|---|---|
| Raspberry | #C3265B | Primary brand color, links, key actions |
| Deep Raspberry | #8E163F | Hover, strong headings, emphasis |
| Warm Gold | #F2C230 | Small accents, selected states |
| Deep Gold | #C99A12 | Fine decorative accents |
| Warm Ivory | #FCF9F5 | Main page background |
| Soft Blush | #F7E8EE | Soft panels and subtle backgrounds |
| Text | #241D21 | Main text |
| Muted Text | #75686E | Secondary text |
| Border | #E9DDE2 | Dividers |
| White | #FFFFFF | Cards and contrast areas |

### Color rules

- Raspberry is the strongest brand signal.
- Gold is an accent.
- Ivory is the primary luxury canvas.
- Avoid large areas of saturated gold.
- Avoid neon pink.
- Avoid pure-black-heavy layouts unless a specific editorial section calls for it.
- Maintain accessible text contrast.

## Typography

Recommended pairing:

- Display: Playfair Display or Cormorant Garamond
- Interface/body: Inter or Manrope

Use serif typography for editorial headings and sans-serif for UI.

## Layout

Use generous margins and whitespace.

Desktop:
- max content width: approximately 1200–1400px
- comfortable horizontal padding
- editorial image proportions

Mobile:
- 16–20px side padding
- 2-column product grids where appropriate
- large touch targets

## Product cards

A product card should contain:

- image
- optional New/Sale label
- product name
- price
- previous price when on sale
- optional color indicator
- optional quick action

Do not fill every card with badges.

## Buttons

Primary:
- Raspberry background
- White text
- subtle hover darkening

Secondary:
- transparent/ivory background
- Raspberry border/text

Text CTA:
- minimal
- editorial

## Navigation

Desktop:
- logo
- Collections
- Shop
- Sale
- About
- Contact
- search
- account/admin if relevant
- cart

Mobile:
- logo
- menu
- cart

## Motion

Use subtle transitions:
- 150–300ms
- opacity
- transform
- image scale on hover

Respect `prefers-reduced-motion`.

## Photography

Prioritize:
- clean backgrounds
- editorial compositions
- fabric texture
- full garment visibility
- consistent image ratios

Do not force a photography style that contradicts actual brand assets.

## Luxury principles

1. Less visual noise.
2. Strong hierarchy.
3. Consistent spacing.
4. Quality imagery.
5. Restrained color.
6. Intentional typography.
7. Clear navigation.
8. Product information before decoration.
9. Whitespace is part of the design.
10. Every decorative element must have a reason.
